## 📌 About the Project

**GlobalTrackCampus Web App** is a web-based application developed using PHP. It organizes travel-related information and provides separate modules for users, bookings, staff, and administrators.

The application is structured to make information easier to access and to support organized management of travel services.

## ✨ Key Features

| Feature | Description |
|---|---|
| 🔐 User Authentication | Registration, login, and logout |
| 🗺️ Destinations | Destination information and listings |
| 🧳 Tour Management | Tour listings and detailed tour pages |
| 🏨 Accommodation | Accommodation information |
| 🚍 Transportation | Travel and transport information |
| 📅 Booking | Booking-related functionality |
| 📖 Travel Guides | Travel information and guides |
| 👤 Customer Module | Customer-related pages |
| 🛠️ Admin Module | Administrative section |
| 👥 Staff Module | Staff-related section |

*Available functionality depends on the implementation in the source code.*

## ⚙️ Installation & Setup

### Prerequisites

- PHP-compatible web server
- XAMPP or another Apache/PHP environment
- MySQL, if required by the application
- Web browser

### 1. Clone the Repository

```bash
git clone https://github.com/Ashfaq12-code/globaltrackcampus-web-apps.git
```

### 2. Move the Project

Place the project folder inside your XAMPP directory:

```text
C:\xampp\htdocs\globetrackwebapp
```

### 3. Start the Server

1. Open the XAMPP Control Panel.
2. Start **Apache**.
3. Start **MySQL** if the application uses a database.

### 4. Configure the Database

- Configure the database connection in the appropriate project configuration file.
- Create the required database.
- Import the provided SQL file if available.
- Use your local database credentials.

### 5. Run the Application

Open your browser and visit:

```text
http://localhost/globetrackwebapp/
```
